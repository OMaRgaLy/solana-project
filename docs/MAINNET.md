# Выход на Solana Mainnet

Приложение переключается на основную сеть одной переменной `NEXT_PUBLIC_CLUSTER=mainnet-beta`. По умолчанию стоит devnet, так что
ничего не меняется, пока вы её не зададите. Но само переключение приложения — это меньшая часть работы: нужно развернуть контракт
в основной сети, завести кошелёк платформы и закрыть несколько пробелов, перечисленных ниже.

## Что переключается автоматически

| Что | На mainnet |
|---|---|
| Демо-режим, демо-кошельки, страница `/demo` | отключены (их ключи публичные, на реальных деньгах их быть не должно) |
| Бот: `/demo`, `/wallet demo`, кнопки демо | отключены |
| Ссылки на Solscan | без `?cluster=devnet` |
| Идентификатор сети в Blink (Solana Actions) | mainnet |
| Бейдж «Devnet» в шапке | скрыт |
| Создание счёта | запрещено, пока не задан `NEXT_PUBLIC_TREASURY` (кошелёк платформы для комиссии) |

## Шаги

1. **Новый ключ программы.** Не используйте ключ с devnet и никогда не коммитьте ключи.
   ```
   solana-keygen new -o ~/steppe-mainnet-program.json
   solana-keygen pubkey ~/steppe-mainnet-program.json
   ```
   Подставьте адрес в `declare_id!` в `programs/steppe_invoice/src/lib.rs` и в `Anchor.toml`, затем `anchor build` (в Windows через WSL).

2. **Рассчитайте стоимость развёртывания.** По умолчанию программа резервирует место вдвое больше своего размера (на будущие обновления).
   ```
   ls -l target/deploy/steppe_invoice.so              # размер в байтах, N
   solana rent <2*N + 45>                             # залог за аккаунт программы
   ```
   Этот залог возвращается только при закрытии программы. Чтобы уменьшить сумму, можно развернуть с `--max-len N`, но тогда обновить программу
   на большую версию без переразвёртывания нельзя. Для развёртывания на кошельке должно быть это количество SOL плюс запас на комиссии.

3. **Развёртывание.**
   ```
   solana config set --url mainnet-beta
   solana program deploy target/deploy/steppe_invoice.so --program-id ~/steppe-mainnet-program.json
   ```
   Ключ, которым развёртывали, управляет обновлениями программы. Храните его отдельно и безопасно; позже передайте мультиподписи (например, Squads) или
   закройте обновления совсем.

4. **Кошелёк платформы (комиссия 1%).** Создайте новый кошелёк (лучше аппаратный) и его адрес вставьте в `NEXT_PUBLIC_TREASURY`.

5. **RPC.** Публичный адрес `api.mainnet-beta.solana.com` ограничен по скорости и режет тяжёлые запросы (вроде списка счетов). Возьмите ключ у платного провайдера
   (Helius, QuickNode, Alchemy), ограничьте его по домену и пропишите в `NEXT_PUBLIC_RPC_URL`.

6. **Переменные на хостинге** (Vercel → Settings → Environment Variables), затем Redeploy:
   ```
   NEXT_PUBLIC_CLUSTER=mainnet-beta
   NEXT_PUBLIC_PROGRAM_ID=<новый адрес программы>
   NEXT_PUBLIC_RPC_URL=<ваш RPC>
   NEXT_PUBLIC_TREASURY=<кошелёк платформы>
   ```
   Плюс переменные бота и Upstash из `docs/TELEGRAM_SETUP.md`.

7. **Первый боевой тест на копейки.** Создайте счёт на 0,001–0,01 SOL, оплатите его вторым собственным кошельком (Phantom) и проверьте в Solscan:
   сплит прошёл, а 1% пришёл именно на кошелёк платформы.

## Пробелы, которые надо закрыть до реальных денег

- **Комиссия не принудительна на уровне контракта.** Сейчас получателя комиссии указывает создатель счёта при создании, контракт этого не проверяет.
  Через сайт и бота комиссия идёт на кошелёк платформы, но технически подкованный пользователь может вызвать контракт напрямую и указать себя. Чтобы 1% был гарантирован,
  нужно изменить контракт (зашить адрес платформы и минимальную долю) и покрыть это тестами до развёртывания в mainnet. Этого я пока не делал, потому что контракт
  нельзя собрать и протестировать без WSL.
- **Контракт не прошёл независимый аудит.** Перед реальными деньгами ограничьте максимальную сумму счёта и скажите об этом открыто.
- **Только SOL.** Цена SOL колеблется между выставлением счёта и оплатой. Для счетов лучше подходит USDC; это следующий шаг после запуска.
- **Курс в акте и налоговая оценка ориентировочные**, не официальные.
- **Юридическая сторона.** Сбор комиссии с платежей в криптовалюте может требовать лицензии или регистрации в вашей юрисдикции. Проконсультируйтесь с юристом.
- **Blink в X** разворачивается только на домене, зарегистрированном в Dialect.

## Откат

Верните `NEXT_PUBLIC_CLUSTER` в `devnet` (или удалите переменную) и сделайте Redeploy: демо-режим и демо-кошельки вернутся.
